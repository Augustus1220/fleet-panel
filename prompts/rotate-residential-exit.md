请把全机所有住宅链的出站同步改到新出口，一处都不能漏：

1. **Xray**：`config.json` 里 `webshare` 出站的 servers 地址/端口/凭据；
2. **HY2 住宅实例**：`/opt/fleet-hy2-webshare/server.yaml` 的 outbounds
   里 http 代理 URL；
3. **面板采集器**：`collect.py` 的 `WS_PLACES` 地点标签（新 IP → 新的
   "城市 · 运营商"描述）；
4. 改完重启 xray 与 HY2 住宅实例，确认 active。

验证（必须做）：从另一台机器经每个住宅通道（住宅 HY2、住宅 VLESS、
住宅 Reality）各拉一次真实流量，查出口 IP 全部等于新 IP；直连通道出
口仍为机房 IP 不受影响。

涉及消费代理商的付费更换次数，先停下来向我确认，禁止随机试抽；旧凭
据不要写进任何汇报与日志。
